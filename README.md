# Flex Hub

Turn your pictures into multi-color 3D prints: keychains, clickers, lightboxes, clocks and 20+ more tools, for Windows and macOS.

- Download: https://flexplayground.co/flex-hub/
- Windows: [FlexHub-Setup.exe](https://github.com/angrybo/flex-hub-releases/releases/latest/download/FlexHub-Setup.exe)
- macOS (Apple Silicon and Intel): [FlexHub.dmg](https://github.com/angrybo/flex-hub-releases/releases/latest/download/FlexHub.dmg)

Flex Hub updates itself. This repository only holds the installers and update files.
